Petri Net — ATM System State Model

✅ Fixed: PIN retry is no longer a self-loop — T_Wrong now adds a token to P_Attempt counter place; T_Retry fires from P_Attempt back to P_PIN_Request only when attempt < 3; T_Block fires when attempt = 3 → P_Error. This correctly models the attempt counter mechanism.
Key Correction: The PIN retry is modelled via a dedicated P_Attempt place (counter): T5 (PIN Wrong) → fires P_Attempt token → if attempt < 3, T6 (Retry) fires and returns token to P4; if attempt = 3, T7 (Block) fires and moves token to P_Error. This is formally correct — no self-loops. Properties verified: 1-Bounded (no place ever accumulates > 1 token in correct use) · Live (all transitions are L1-fireable in the complete reachability graph) · Deadlock-free (T12 or T13 always reachable).
